Graficos Gestão

Nome Imagem Filtros do Visual Filtros de Seleção Resumo
Total Horas (Realizado) - - Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Soma de todas as horas apontadas nas atividades, incluindo tarefas com status Concluído.
Total Horas (Previsto) - - Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Soma das horas do campo Estimativa Original, incluindo tarefas com status Concluído.
Horas Vendidas - - Projeto Responsável, Projeto Nome, Projeto Categoria Soma das horas da Estimativa Original dos cards do projeto HIS.
Qntd. Projetos Ativos - - Projeto Responsável, Projeto Nome, Projeto Categoria Contagem Distinta dos Projetos pela Chave.
% Realizado x % Previsto - - Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Compara o percentual de horas realizadas e previstas por cliente/projeto. O ideal é manter equilíbrio próximo de 50% previsto e 50% realizado. Quando o realizado supera o previsto, indica consumo acima das horas vendidas/planejadas (estouro de horas).
Marcos do Projeto Atividades - Tarefa Status != Concluído and Marco do Projeto = Sim Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Lista as tarefas onde o campo Marco do Projeto é marcado como "Sim". Tarefas concluídas são desconsideradas.
Distribuição das Horas Restantes por Tipo (%) - Tarefa Status != Concluído and Tipo != Atividade de Gestão, Oportunidade Identificada, Tarefa and Hrs Restantes > 0 Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Mostra a participação percentual das horas restantes por tipo de atividade. O valor exibido no centro representa a soma total das horas restantes. Exclui atividades em que o Tipo é Gestão, Oportunidade Identificada e Tarefa. Tarefas concluídas são desconsideradas.
Distribuição das Tarefas por Tipo (%) – Geral - Tarefa Status != Concluído Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Mostra a distribuição percentual da quantidade total de tarefas por tipo. Tarefas concluídas são desconsideradas.
Distribuição das Tarefas por Tipo (%) - Tarefa Status != Concluído and Tipo != Atividade de Gestão, Oportunidade Identificada, Tarefa Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Mostra a distribuição percentual das tarefas por tipo, desconsiderando atividades administrativas/gestão. Exclui atividades em que o Tipo é Gestão, Oportunidade Identificada e Tarefa. Tarefas concluídas são desconsideradas.
Tarefas por Tipo - Tarefa Status != Concluído and Tipo != Atividade de Gestão, Oportunidade Identificada, Tarefa Data Limite, Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Mapa de calor que apresenta a quantidade de tarefas por tipo e responsável, facilitando a identificação de concentração de demanda e carga operacional. Exclui atividades em que o Tipo é Gestão, Oportunidade Identificada e Subtarefa. Tarefas concluídas são desconsideradas.
Tarefas por Fase - Tarefa Status != Concluído and Tipo != Atividade de Gestão, Oportunidade Identificada, Subarefa, Tarefa Data Limite, Projeto Responsável, Projeto Nome, Fase do Projeto, Projeto Categoria Exibe a quantidade de tarefas por fase do projeto e status atual, permitindo acompanhar a distribuição das atividades ao longo do fluxo de implantação. Exclui atividades em que o Tipo é Gestão, Oportunidade Identificada e Subtarefa. Tarefas concluídas são desconsideradas.
